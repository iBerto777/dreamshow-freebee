# DreamShow — FreeBee winners feed

Public, deliberately boring: one JSON file the FreeBee attract screen on mydreamshow.com reads
to show who won the latest drawing.

- `winners.json` — latest draw. First name + last initial only. **No email addresses, ever.**
- Written by `drawing/publish_winners.py` in the private `DreamShow_Drawing` repo, from that
  draw's audit record. Nothing here is hand-edited.

Why public: the drawing is machine-run and nobody should have to take our word for who won.
The board is the receipt.
